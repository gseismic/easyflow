## 界面与场景

凌晨查看昨晚执行为本轮明确的高频场景：默认“最近”，紧邻日/周/月；输入小时数并应用，默认 24，可设 1–168。小时数记在当前浏览器，切换工作流与刷新后保留；固定日期模式仍按需选择。最近模式显示响应中的实际跨日起止日期时间，按服务端当前时刻每轮滚动，首尾不足半小时的格子按实际范围显示。

周/月点击一个已到达的日期，在原汇总下展开该天半小时图。展开标题显示日期，提供收起；格子高度 20px、间距 2px，原图保持 32px/4px；窄屏在图内部滚动。新一天替换旧一天，未来日只显示“尚未到达”，不请求展开。原“查看当天”保留为可选全尺寸查看，展开无需切走周/月。加载、错误重试和红格日志在当前区域呈现。

按哈夫曼五维复核：跨午夜记录与按天细节均与监控目标直接相关；最近入口容易到达，小时设置紧邻当前范围；日细节仅选中时占位，不长期占据首屏；通过日期标题、选中轮廓和局部加载状态建立层级。

## API 和状态

复用 `GET /api/workflows/uptime`，新增可选 `lookback_hours=1..168`。与显式 start_at/end_at 互斥，只适用 half_hour；缺少两种范围或混用返回输入错误。旧 start/end、day 粒度、时区和登录权限保持；无需新路由或新业务写入。选择服务端相对参数，避免浏览器时钟偏差、动态 URL 导致请求状态重置和每轮销毁时间图。

固定服务器 now，一次查询得到 `[now-X小时, now)`，UTC 半小时边界构造中间格子、首尾裁剪，响应 as_of/end_at 同一时刻。最多 337 格，最多 100 个工作流；失败详情沿用每格范围和半开边界。当前等待属于查询快照，在滚动范围末格显示。绝对范围原有 25 小时限制不变。

滚动格子的标识按半小时桶稳定，选中失败时固定那次范围，轮询不重建已展开日志。周/月日图用独立查询，仅当前选中一天加载；收起或换日时取消旧请求。嵌套 Escape 先处理内部选择，避免一次按键同时关闭上层。设计已自查输入错误、存储失败、DST、凌晨、日期替换及请求竞态。
