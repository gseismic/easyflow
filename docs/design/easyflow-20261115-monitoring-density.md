## 场景与现状

`[假设]` 优先照顾“在工作流之间查看状态 → 选择错误时段 → 查看失败和原始日志”，其次是选择运行、任务和日期，手动触发/暂停仍易达。没有真实频率统计，不据此删除管理功能。用户已要求按前轮哈夫曼评审优化现有界面并循环审查。

沿用绿/白 tokens、既有字阶、8/16/24px 间距、语义状态色和 44px 操作区域。当前辅助页头和时间图标题/说明叠加，导致 1440×900 下运行选择从 y=879 开始；优化结构与间距，不用缩小正文换空间。

## 结构与取舍

```text
左侧：全部工作流 / 运行历史 → 明确筛选左侧的搜索框 → 项目与工作流

右侧：←  工作流名称 / 启用、调度、任务数、离线影响       刷新 / 暂停 / 触发
      概览 | 任务 | 运行历史 | 日志 | 调度详情 | 源码
      ┌ 运行时段  日/周/月  ← 日期 → 今天   单位/本地时间  说明 ▸ ┐
      │ 图例：有执行 / 执行中 / 等待 / 错误 / 无执行 / 未来      │
      │ 时间格与刻度 → 原位错误信息 / 完整尝试日志               │
      └─────────────────────────────────────────────────────┘
      运行记录：运行选择、状态、时间与耗时
```

- **重要性/层级**：左树与详情标签继续直接可达；不隐藏基础搜索与筛选。返回按钮保持过滤后的返回地址，并提供可访问名称和提示。
- **空间**：删除详情英文眉题和独立返回行；合并时间图标题和控件；压缩卡片边距，保持数据可读及可操作。
- **驻留**：图例、单位和时区常驻；较长语义解释用原生 details 展开。详情仅保留一个总刷新入口，图表错误时仍有明确重试。
- **显著性**：错误色与原位失败面板保留；管理操作使用次级样式。离线后果在元信息中显示，避免重复的大面积提示。
- **一致性**：列表/全局历史/历史运行详情使用相同的紧凑页头与卡片间距，保持当前权限、URL 和运行上下文。

## 状态与响应式

加载状态保留目标标题和标签，禁用旧管理入口；错误状态保留可读错误和重试；无运行保持触发引导；缺失定义仍可访问已保存的历史日志。长名称允许换行，操作组可换行；窄屏继续使用原生导航抽屉，返回/关闭/Esc/焦点恢复行为不变。

日期控件把“前一周期 / 日期 / 后一周期”作为连续操作组，过窄时让“今天”和范围说明换行，避免箭头与目标字段分离。详情标签在窄屏保持一行，过窄时在标签条内横向滚动，Tab 焦点可到达后面的源码入口；只读账户的五个标签保持可达。解释展开可以占用更多空间，不把默认态密度作为压缩错误详情的理由。

已复核：不新增统计定义、不把红格当作当前运行失败，不删除调度器离线后果提示，不使只读用户获得管理操作；交互变化需要覆盖共享控件、历史入口和最终构建的实际浏览器验证。
