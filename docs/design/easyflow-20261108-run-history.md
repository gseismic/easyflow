## 场景和现状

管理员和只读用户需要快速查找一次执行、定位失败并查看任务日志。现有首页是工作流列表，详情通过下拉框选择最近 100 次，无法直接浏览跨工作流的全部历史。沿用既有绿色、白底、语义状态色、列表表格、字体和紧凑导航，避免引入另一套视觉体系。

## 信息结构

[假设] 最常用路径是：主导航「运行历史」→ 按工作流或状态缩小范围 → 按入队时间找到一条 → 点击查看任务及日志。基于用户明确指定的栏目和既有页面结构，沿用现有列表与详情模式。

```text
easyflow   工作流   运行历史                    调度器 · 用户

运行历史                         刷新
所有工作流的执行记录，按入队时间从近到远
搜索工作流 [搜索]        全部 / 运行中 / 排队中 / 成功 / 失败
工作流        状态        触发方式     入队时间     耗时      查看 →
... 实际记录 ...
                         上一页    第 N 页    下一页

← 返回运行历史
工作流名称  ·  运行状态
触发、入队、开始、结束、耗时、逻辑时间、数据区间
任务列表（按记录显示状态）       选中任务详情与日志
```

首要信息是运行列表和每条状态；搜索、筛选和分页为次要操作；记录详情保留与来源工作流的入口。历史定义不可复原时只显示实际记录，不捏造上下游；原工作流已移除时仍可查看历史任务与日志。

## 状态与可访问性

提供加载、没有任何记录、筛选无结果、请求错误、无任务及日志缺失状态。状态采用文字与颜色共同表达；筛选和导航可键盘操作；窄屏中每条记录换成多行，保留状态、入队时间和耗时，长 ID 截断并提供完整文本。时间标注为浏览器本地时区。

## 假设与开放问题

[假设] 默认不筛选，以入队时间倒序、每页 25 条展示；状态和工作流是本次最常用的筛选条件。历史定义和已删除数据的恢复不在本次范围。
