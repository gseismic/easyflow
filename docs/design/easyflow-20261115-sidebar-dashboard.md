## 现状认知与输入

当前是绿色、白底的单机 Web 控制台，顶部含工作流/历史、调度器和账户；工作流主表支持搜索和项目/标签/状态过滤，逐行包含日周月时间图。详情通过返回列表切换工作流，运行时段、运行信息、依赖图和任务日志纵向排列。已有项目归属由 `project:` 标签表达，普通标签是横向分类。

服务场景：在多个工作流之间反复切换、从项目定位某个流程、从异常时段进入失败日志。用户已明确偏好左右结构，并在项目→工作流的线框讨论后要求设计实施。

`[假设]` 桌面左栏固定约 272px，右侧占余下宽度；1000px 及以下采用抽屉。`[假设]` 导航搜索独立于右侧列表搜索；状态按用户和浏览器标签页保留，选中工作流由地址决定。以上是本轮可调整的实现选择，不引入新的业务概念。

## 结构与信息层级

```text
easyflow                         调度器状态 / 账户
─────────────────┬────────────────────────────────────────
全部工作流        │ 项目或工作流标题 / 当前状态 / 管理操作
运行历史          │
查找导航工作流    │ 概览 | 任务 | 运行历史 | 日志 | 调度 | 源码
▾ 项目 A          │ ──────────────────────────────────────
    工作流 1      │ 当前标签内容
    工作流 2      │ 概览：时间图、红格失败面板、运行信息
▸ 项目 B          │ 任务：运行选择、依赖图、选中任务详情
▸ 未分组          │ 日志：运行与任务选择、对应日志、重跑预览
─────────────────┴────────────────────────────────────────
```

P1 为工作流定位与当前工作区；P2 为所选工作流的内容标签和当前运行；P3 为调度、源码及管理辅助操作。顶部只保留品牌、抽屉开关、调度器和账户；全局页面入口放左侧，避免重复导航。主操作继续为管理员触发运行，其余操作使用次级样式。

项目节点有独立展开按钮和项目概览链接。展开只控制左树；点击项目名称进入其概览，并保留右侧既有关键词/标签/状态，所有过滤继续可见。“全部工作流”清除列表限制并显示完整概览。普通标签继续留作过滤。树不承载任务依赖关系，任务标签中的 DAG 图保留汇合/分叉。

右侧默认“概览”，沿用原无 tab URL；新增“任务”“日志”，保留历史、调度和管理员源码。选择运行与任务在同一工作流标签间保留，刷新保留工作流/标签路由；日志按当前明确选择读取，切换运行清空尝试选择。历史失败入口继续锁定原始 attempt。

## 导航数据与状态

复用现有内部接口，不扩充后端：`/api/workflows/facets` 负责项目和匹配统计，展开项目时通过 `/api/workflows` 查询对应分组，每批 50 个、cursor 翻批。只请求展开分支，覆盖各批次中的当前工作流而非主表当前 25 个；项目和搜索变更重置该分支分页。

导航搜索覆盖工作流、项目、描述、标签和任务 ID，支持中文组合输入；仅筛选左树，常驻提示其范围。当前工作流由详情已读取的元信息定位，直达地址自动展开所属项目；若不在当前批次或搜索范围，提供单独的当前项入口。历史工作流定义不可用时保留 ID 和历史内容，不把缺失定义归为“未分组”。

展开、搜索和滚动存入按账户区分的 sessionStorage；地址负责选中项。数据只包含导航状态，不含日志、凭据或运行数据。存储不可用、损坏或旧格式时回到安全默认值。导航保持挂载，切换右侧页面不重建左树。

| 状态 | 展示与恢复 |
| --- | --- |
| 默认 | 项目分组、数量、工作流名称和当前状态；选中项高亮 |
| 加载/发现中 | 保留可用记录，提示正在发现；数量不显示伪零 |
| 搜索无结果 | 明确仅左树没有匹配，可清空导航搜索 |
| 无工作流 | 告知放入 DAG 文件后出现，保留全局历史入口 |
| 请求失败 | 显示错误与重试，已有记录须注明可能旧数据 |
| 当前项不在本批 | 当前项单独可见，不据此判断删除 |
| 定义不可用 | 保留工作流 ID；历史任务与日志按已保存数据显示 |
| 长名称/多项目 | 名称截断并可看完整名称，左树独立滚动，分批可达 |
| 窄屏 | 原生模态抽屉；关闭/遮罩/Esc/导航后关闭并恢复焦点 |

## tokens、键盘与响应式

沿用深绿 `--ink/--green`、浅绿选中背景、白色纸面、`--border`、既有语义状态色。使用 8/16/24/32px 间距和 8px 圆角；树节点和操作至少 44px 高，标题层级沿用现有字阶。

导航采用语义列表、展开按钮和链接，保持原生 Tab/Enter/空格；分支按钮可用左右键展开/收起，工作流链接向左可回到所属项目。展开状态由 aria-expanded 表达，当前链接由 aria-current 表达，状态同时提供文字。导航无需模拟不完整的 ARIA tree。

桌面左栏与顶部保持可见，右区独立自然滚动；窄屏由原生 dialog 限制焦点并阻止后台交互。跨断点关闭模态后转为桌面导航，防止遗留遮罩或 inert。任务图、表格和时间图的必要横向滚动限定在组件内，页面不溢出。

## 取舍与复核

把主表当前页直接作为导航会漏掉工作流；一次下载全部流程会扩大轮询成本。选择按项目展开、分批查询，复用已有搜索、统计与权限契约。由详情报告归属，避免重复拉取完整详情来定位树。

已复核：全局历史和原失败日志入口继续可达；右侧搜索/基础筛选常驻；新增标签不移除管理操作；viewer 源码限制不变；抽屉既可键盘退出也能适应断点变化。本次没有数据库、SDK 或业务权限设计变更。
