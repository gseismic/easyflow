## 目标与价值

以任务为行、最近多次运行为列，定位反复失败的任务及上游阻塞，减少逐次打开运行详情的操作。

## 范围与完成标准

- 优先在工作流详情提供规模有界的最近运行矩阵，使用已保存的任务状态；任务定义变化或工作流移除时不伪造历史任务。
- 支持区分失败、上游失败、跳过、等待和未保存记录，不把缺失状态显示成成功。
- 单元格可定位运行、任务及明确的尝试/日志，历史失败与当前状态的展示语义需在实施前确定。
- 大任务量和窄屏可浏览，加载、空、错误状态明确；验证不同版本任务集合和状态变化。
- 先评估与当前依赖图、运行历史的关系，建立计划后再实施。
