## 目标与范围

在工作流详情新增“运行历史”标签，按精确工作流 ID 展示完整历史，而不限于运行选择器最近 100 次。支持按运行和历史任务 ID 搜索、状态过滤、分页、查看任务和日志，并返回同一工作流历史；搜索、过滤和分页不受全局列表条件影响。只读用户也可访问。沿用现有接口、视觉样式及认证权限；不修改数据、调度或 DAG。保留全局运行历史及现有链接兼容性。

## 设计与当前依据

现有详情页有运行与任务、调度详情、源码标签；运行选择器限制最近 100 次，“查看全部运行”跳转至全局历史。`GET /api/history/runs` 已有精确 `dag_id`、状态、搜索及游标分页；历史详情接口可读取原运行保存的任务与日志。[假设] 用户最常见动作是从当前工作流查看较早或失败的运行，然后返回列表继续查找。复用现有标签、搜索、状态按钮、列表及错误/空态，设计范围见 `docs/design/easyflow-20261108-workflow-run-history.md`。

## 验收、风险与回滚

- 不同工作流即使 ID 有共同前缀也不混入；全局搜索及项目标签选择不会隐藏该工作流历史。
- 浏览器地址可恢复当前标签和搜索、状态；同一会话内从详情返回恢复当前分页，刷新后从第一页开始。
- 查询失败要展示可重试错误，不将失败显示为空结果；超长 ID 和小屏内容可阅读。
- 不运行真实任务，不写真实数据库。回滚可恢复本次前端及文档修改；保留此前已有资源和工作区内容。
