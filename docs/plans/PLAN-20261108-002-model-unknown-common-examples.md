- 实时扫描可能令定时示例自动执行：新增定时例只输出演示信息；量化 DAG 的固定开始时间选在上一个与下一个每日刻度之间，保证当前可手动执行且下一次自动调度仍在下一个刻度，避免改动当下立即写入已有目录。旧运行重跑可能受源码哈希保护，保留数据库供用户查看。
