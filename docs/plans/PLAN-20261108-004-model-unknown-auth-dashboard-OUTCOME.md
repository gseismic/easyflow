## 边界与遗留事项

- 源码视图显示当前 DAG 文件；既有系统不保存历史源码快照，界面不会将当前文件冒充历史源码。只读用户可以查看日志，日志仍可能含业务数据或代码片段。
- Web 保持仅监听本机，不提供公网或 TLS；登录限流为单个 Web 进程内的短期限流。用户读取初始凭据后应删除文件，必要时使用 CLI 重置密码。
- 原有 Web 收到 `SIGTERM` 后可能遗留 scheduler 的问题仍未解决，见 `docs/known-issues/KI-20261108-1718-001-web-sigterm-orphan-scheduler.md`；本次使用已验证的 `SIGINT` 路径切换服务。
