- 修复公共调度行为会影响所有有历史的 cron 和 `timedelta` 工作流；以 UTC 瞬间比较并保留时区、历史推进及 `catchup` 语义，增加边界和真实状态库测试。已有运行不做隐式清理。

- 运行中的进程不会自动加载核心 Python 修改；如需重启，先检查是否有正在执行的任务，使用正常终止并保持数据库不变。回滚只针对本任务跟踪的代码、测试和文档，不动用户数据。
