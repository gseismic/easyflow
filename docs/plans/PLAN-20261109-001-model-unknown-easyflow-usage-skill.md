## 目标与范围

在 `skills/easyflow-usage/` 创建基于当前实现的使用型 Skill，使使用者能够选择合适的 DAG 写法、运行方式和管理操作，并理解实际执行和调度的关键边界。按需使用独立参考文件，避免把整个项目手册复制到入口。

不修改 easyflow 的功能、项目目标、现有示例或用户的运行数据库；不安装 Skill 至其他目录，不启动真实调度器，不触发外部业务任务。
