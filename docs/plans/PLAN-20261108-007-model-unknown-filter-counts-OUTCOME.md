## 完成情况

- 标签支持全选当前搜索结果和全部不选，多个标签匹配任一项；不选标签包含没有普通标签的工作流。项目及标签徽标支持直接筛选。
- 项目下拉显示项目总数，以及各项目覆盖全部分页的当前匹配数和总数。工作流页按工作流计数，历史页按运行次数计数；统计包含当前搜索、状态与标签条件，项目选择本身不限制其他项目的计数。发现未完成或出错时标注未知，界面显示统计时间。
- 统计通过只读接口计算，按条件和工作流当前元数据短时缓存，并合并同条件并发请求；前端按页面需要刷新。为大量项目避免了逐项重复扫描计数结果。
- “重置全部”清除当前页面的搜索、状态、工作流限定及共享项目和标签。工作流详情新增“查看全部运行”，按精确 DAG ID 进入完整历史；查看运行详情后返回仍保留工作流范围及页码。历史页面显示当前匹配总数。
- 用户说明、UI 与接口设计见 `README.md` 和 `docs/design/easyflow-20261108-filter-counts.md`。未创建独立项目表、修改已有 DAG 文件或重跑业务任务。

## 偏差与边界

- 无本次范围内待处理的问题。计数是带时间的短期缓存快照：界面通常每 15 秒刷新，后端对同条件最多缓存 5 秒，因此数量可能短暂滞后；列表和运行状态独立刷新。
- 历史按当前定义归类，已移除的工作流归入“项目未知”；不存在可预先创建、没有 DAG 的独立项目实体。历史时间筛选与“同时包含所有标签”切换按计划留待实际需要时再评估。
