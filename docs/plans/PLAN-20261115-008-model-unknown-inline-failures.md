## 验证与完成标准

- 日、周、月中的红格均在原位展开，列表和详情共享行为；常驻筛选及默认日视图不回归。
- 时段内所有失败尝试可分页访问，重试成功、多个任务或多次失败不会被最新状态覆盖；无尝试记录时明确说明，不能伪造错误原因。
- 选择失败项后日志请求指定任务和 try_number，链接可打开同一次尝试；加载、失败重试、空、不可用日志、长文本和请求竞态有正确表现。
- 未登录接口返回 401，viewer 可以读取，接口无写入；非法参数被拒绝。单次响应至多 100 项，错误摘要和日志显示均有界。

## 风险与回滚

- 失败运行和任务尝试可能重复：同一时段已有任务失败时不再增加运行级兜底，运行数按 run_id 去重；其他时段的运行失败仍按原 uptime 语义展示。
- 任务最后状态可能已成功：详情使用 task_try 的历史错误和时间，当前状态单独标注。
- 高频时段与长日志：按需查询、有界分页，只对选中尝试读取日志；分页期间记录变化可能改变页内容，刷新后以当前数据库为准。
- 构建会清空 static：构建前保存已有已跟踪资源并恢复旧资源，仅更新入口、添加新资源，不清理用户文件。
- 回滚只撤销本次接口、面板及入口改动，保留运行数据库、既有代码和用户文档；无需数据迁移。
