## 风险与回滚

- 项目节点和主内容过滤相互干扰：导航查询独立，项目链接只替换项目范围，保留右侧已显示的其他过滤；“全部工作流”明确回到未过滤概览。
- 异步解析/分页使当前项不在本批：当前项单独定位展示，不能误报工作流已删除；加载下一批有边界和错误重试。
- 详情标签改变日志加载条件：仅在日志标签读取日志，切换运行清除 attempt；失败历史详情保持原路径与明确尝试。
- 抽屉生命周期和焦点：使用原生 dialog，跨断点先关闭模态再进入桌面布局，保证后台内容可交互。
- 构建清空 static：保留旧已跟踪资源，只更新入口并增加当前新资源。
- 回滚只撤销本轮前端和文档，不涉及数据库迁移或用户运行数据。
